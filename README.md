# XOS - My Web OS

hey! this is **XOS**, my very own OS that runs directly in the browser. i built this using simple HTML, CSS, and JS so its easy to understand and mess around with.

## what's inside

i kept it simple and normal with just the basic apps you actually need:

- **Calculator** - for doing basic math stuff (+, -, *, /)
- **Notes** - a simple notepad to write things down (it saves your text automatically and lets you download it as a `.txt` file)
- **Command Prompt** - a basic terminal where you can run simple commands like `help`, `ver`, `date`, `time`, `echo`, `color`, and `cls`
- **Paint** - a small drawing app where you can pick colors, change brush size, erase, and doodle
- **About** - shows basic info about the OS and lets you change the desktop wallpaper

## features

- **Draggable windows** - you can click and drag any window around the screen, minimize, maximize, or close them
- **Easy custom background** - there is a background image placeholder in the code (and inside the About app) so you can easily put whatever wallpaper URL you want
- **Taskbar & Start Menu** - works just like a normal desktop with a working clock at the bottom right

## how to run it

you dont need to install anything.
1. download or clone this repo
2. open `index.html` in any web browser
3. thats it, it just works!
